# Памятка Для Ноутбука

## Вариант 1. Из Одного `.run`

```bash
chmod +x vnc-watch-installer.run
./vnc-watch-installer.run
```

Если хотите поставить не в `~/vnc-watch`, а в другую папку:

```bash
./vnc-watch-installer.run /нужный/путь/vnc-watch
```

После установки:

1. Откройте ярлык `Мониторинг VNC`.
2. Введите пароль `sudo`.
3. Проверьте, что появился значок в трее или, если tray недоступен, начали приходить уведомления.

Для просмотра истории используйте ярлык `Лог VNC`.

## Вариант 2. Из Папки Проекта

```bash
chmod +x setup.sh
./setup.sh
```

После этого будут созданы ярлыки на рабочем столе.

## Если Что-то Пошло Не Так

Запуск вручную:

```bash
./launch-monitor.sh
```

Лог запуска:

```bash
tail -n 50 logs/tray-start.log
```

## Что Должно Работать

- уведомления о входящем VNC-подключении
- уведомления об ошибке аутентификации
- уведомления об успешном подключении
- уведомления об отключении клиента
- просмотр истории через `Лог VNC`

## Что Уже Учтено

- пути с пробелами
- отсутствие tray: будет fallback на фоновый режим с уведомлениями
- отсутствие `notify-send`: мониторинг не падает
- ошибки запуска не закрывают окно без сообщения
