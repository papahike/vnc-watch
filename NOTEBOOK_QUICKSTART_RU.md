# Быстрый запуск на другом компьютере

## Вариант 1: один `.run`-файл

На исходном компьютере соберите установщик:

```bash
./build-installer.sh
```

Перенесите `dist/vnc-watch-installer.run` на целевой компьютер и выполните:

```bash
chmod +x vnc-watch-installer.run
./vnc-watch-installer.run
```

По умолчанию файлы будут установлены в `~/vnc-watch`. Другой каталог можно
передать первым аргументом.

## Вариант 2: папка проекта

```bash
chmod +x setup.sh
./setup.sh
```

Установщик создаст на рабочем столе ярлыки `Мониторинг VNC`, `Лог VNC` и
добавит VNC Watch в автозапуск GNOME/MATE.

## Первая проверка

1. Откройте ярлык `Мониторинг VNC`.
2. Введите пароль текущего пользователя, которому разрешён `sudo`.
3. Убедитесь, что появилась tray-иконка или уведомление.
4. Выполните тестовое VNC-подключение и откройте `Лог VNC`.

Фоновый автозапуск не использует `sudo`. Текущему пользователю нужен прямой
доступ к журналу `x11vnc`; после добавления в соответствующую группу следует
полностью выйти из графического сеанса и войти снова.

## Диагностика

```bash
./launch-monitor.sh
tail -n 50 logs/tray-start.log
tail -n 50 logs/autostart.log
```
